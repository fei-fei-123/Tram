# 快速开始

这篇文档带你从零写出一个最小的插件：Hello。它会在每个轮次里向会话添加一条 AI 消息"Hello!"——就像一个只会说 Hello 的假 LLM。读完这篇，你会走完一个插件的全部要素：对象、注册、工厂、Manifest、安装启用，最后在日志里看到自己。

> 伪代码约定：本文所有代码均为语义示意。形如 `self.xxx(ctx, ...)` 的调用，表示向通信层提交对应的操作（见[[上下文设计#操作 Operation|操作]]），这些方法由插件自行实现，程序并不提供。

## 写出来一个对象

插件首先是一个普通的类。Tram 不关心你的插件"是"什么，只关心它能做什么。我们给 Hello 一个 `turn` 方法：收到本轮的 ctx，添加一条 Hello 消息，然后把控制权交给链的下游。

```python
class HelloPlugin:

    def turn(self, ctx):
        # 像 LLM 一样，向会话末尾添加一条 AI 消息
        self.add_msg(ctx, "Hello!", "AI")
        # 执行链的下游。如果你是链的最后一环，它什么也不做
        self.do_filter(ctx)
```

两个要点：

1. **一切修改经通信层**。`add_msg` 是"提交一次会话级 Add 操作"的语义示意，对应[[上下文设计#添加一条消息 Add|添加一条消息]]。不要直接修改上下文对象——插件拿到的是克隆，改了也不会生效。
2. **do_filter 不是可选项**。不调用它，链的下游全部断路。除非你有意打断（见[[插件设计]]），否则做完自己的事就交棒。

## 挂载到生命周期

Tram 不会凭空知道该在什么时候调用 `turn`。你需要把它注册进某个生命周期的插件链。插件的 `on_load` 方法在装载时被调用，在这里完成注册：

```python
class HelloPlugin:

    def on_load(self, ctx):
        # 把 turn 方法注册进 onTurn 链
        self.res_filter(ctx, "onTurn", self.turn)

    def turn(self, ctx):
        self.add_msg(ctx, "Hello!", "AI")
        self.do_filter(ctx)
```

`onTurn` 是轮次生命周期：每个轮次都会完整执行一次这条链（见[[生命周期#轮次开始与结束 onTurn|onTurn]]）。所以 Hello 会在每一轮被调用一次。换成别的生命周期，行为就完全不同——**注册到哪里，决定了你包裹谁、被谁包裹**。

## 创建一个工厂

程序通过工厂方法取得插件实例，并且只取一次：启动时所有安装过的插件都会被装载与管理，无论是否启用（见[[插件链#插件实例|插件实例]]）。所以工厂要始终返回同一个实例：

```python
_plugin = HelloPlugin()

def create_plugin():
    return _plugin
```

## 提供一个 Manifest

Manifest 是插件的自我说明。程序读取它来装载你的代码、调用你的方法；日志中的插件身份也来自这里，不由插件自报。

`manifest.json`：

```json
{
    "id": "hello",
    "name": "Hello",
    "description": "模拟LLM，在轮次里添加一条Hello消息",
    "version": "0.0.1",
    "entry": {
        "file": "hello.py",
        "factory": "create_plugin"
    },
    "methods": [
        {
            "lifecycle": "onLoad",
            "method": "on_load"
        }
    ]
}
```

至此插件完成。目录结构：

```
hello/
├── manifest.json
└── hello.py
```

## 安装与启用

参考[[术语说明#安装与启用|安装与启用]]：

1. **安装**：把 `hello` 目录放进程序的管理目录。此时插件已被程序管理，但不会运行。
2. **启用**：在程序中开启它。从下一个新会话开始，Hello 将参与轮次。

## 跑起来

新建一个会话，随便发一条消息。一个轮次被拉起：Hello 在 `onTurn` 链上被调用，会话末尾多了一条 AI 消息"Hello!"。没有插件申请续轮，回复到此结束.（见[[流程控制#等待用户|等待用户]]）。

> 一个实验：Hello 没有申请续轮，链上也没有别人——它就是这次回复的全部。试着再写一个 World 插件，同样注册到 `onTurn`，观察两个插件如何按顺序共同组成一次回复；交换两者的启用顺序，包裹关系随之改变（见[[认识插件]]）。

## 在日志里看到自己

打开操作日志，你会看到一条记录：插件 `hello` 提交了会话级 Add 操作，role 为 AI，内容 "Hello!"，状态 ok。插件 id 来自 Manifest，不是你自己声称的。

这就是 Tram 的调试方式：**读日志，复现回复**。读操作同样入账——插件做过什么，用户就能看到什么。
