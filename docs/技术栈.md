# Tram 宿主页 · 技术栈（2026-11-09 定）

| 层 | 选型 | 说明 |
|---|---|---|
| 后端 | Python + FastAPI | websocket 推事件流；存储 stdlib sqlite3 |
| 前端 | React + TSX（Vite 构建） | 用户定，动机：后续移植手机、手机上体验 |
| 移动端一期 | 响应式 PWA | 手机浏览器直接用，不写原生 |
| 移动端二期 | React Native（如需） | 前提见下方保护线 |

## 移植保护线（架构约束，前端开工前必读）

- **业务逻辑不进 React 组件**：websocket 通信、状态管理、API client 全部收敛在可移植层（hooks/services），组件只做渲染
- 样式响应式，断点按移动端优先设计
- 插件 UI 一期走**声明式描述符**（宿主内置组件库渲染按钮/面板/卡片/Markdown）；自定义组件逃生舱（web component / iframe）二期再开
- 页面是事件流的普通订阅者（域模型.md 已定）：websocket 收到 UI 树/事件后渲染，无特权路径
